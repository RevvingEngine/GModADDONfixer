# GModADDONfixer
Фиксер для крякнутых модов гмода.
> [!IMPORTANT]
> AI Slop

Что он делает:
- Переименовывает одинаковые названия .gma файлов
- Распаковывает .bin файлы и переделывает их в .gma

Использование:
```
python gmod_addons_fix.py "путь к папке addons"
```
### Немного инфы по .bin файлам:

Если кому-то не похуй,то .bin файлы которые скачивает WorkshopDL/сам Steam это самый обычный LZMA архив,который можно открыть
даже через 7-zip,если убрать .bin и подставить .LZMA. Внутри будет сам аддон,но без .gma,если его оттуда вытащить и добавить
расширение .gma через переименование,то получим обычный рабочий аддон.
Стим работает по такому уебанскому методу чтоб сжать аддон и чтобы он не занимал много места на диске если не юзается.
лицуха GMod распаковывает это все через обращение к Steamworks API во время запуска,поэтому на лицухе он и работает.
